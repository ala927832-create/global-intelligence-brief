# Global Intelligence Brief｜內容深度編輯標準

**版本用途：** 研究流程與六章節已由 `config/frozen_contract.json` 凍結，這份文件只補充編輯驗收細則；更改原有五層流程、六章、四時點、Layout 01 或發布策略，必須事先取得專案擁有者確認。

**參考原則：** 參考 Wall Street Journal 的新聞主次安排，以及 The Economist *The World in Brief* 的短訊／完整事件解讀分層。不重製或模仿其文章、付費新聞全文、圖片或受著作權保護的編輯素材。

## 編輯金字塔

| 編輯層 | 目標 | 真正新增的價值 |
| --- | --- | --- |
| 01 Executive Brief | 3 個有根據的重大事件 | 本日世界變化、判斷與風險；不是抄 3 次標題 |
| 02 The World in Brief | 8–12 則精選 | 清楚的何時／何地／何事／來源；非頭條快速閱讀 |
| 03 Essential Analysis | 3–5 則具體事件 | 背景、因果機制、影響範圍、資料限制及下一項觀察 |
| 04 Deep Research | 2–3 則真正深讀專題 | 新增官方證據、歷史口徑比較、反例、不同情境、可推翻條件 |
| 05 What Changed | 晚報與晨報的實質差異 | 新事實→原本推論改變了什麼→後續需要查什麼 |
| 06 Sources & Evidence | 証據索引與日期 | 分開：媒體來源聲稱、原始官方文件、研究推論、未核實內容 |

**文字優先繁體中文。** 專有名詞保留英文原名；不重複整篇中英正文。標題再好看也不能替代研究。

## 逐篇研究的審稿問題

1. **發生什麼？** 文章來源、實際發生日期與公布日期是否區分？是否把舊背景當作今日新聞？
2. **證據是什麼？** 每個關鍵數字有期間、單位、調整口徑、來源 ID、原始來源可定位位置嗎？
3. **為何重要？** 至少解釋事件和政策／市場／產業的具體關係，不用無法檢驗的空話。
4. **如何傳導？** 用「事件 → 中間指標 → 經濟或產業結果」描述條件式路徑，不把相關性當因果性。
5. **有何反例？** 至少提供合理替代解釋與可以推翻結論的證據；必要時說明目前缺少什麼。
6. **歷史比較可靠嗎？** 說明不同制度、期間、指標口徑與不可比之處。無數據時不得杜撰年份或數字。
7. **下次怎麼檢查？** 明確的待觀察公告、數據或狀態，不只是「繼續關注」。
8. **讀者獲得了什麼？** Deep Research 必須提供 Essential 沒有的資料或研究角度，不得只換句話重寫。

## Gemini 兩輪（不變更已凍結架構）

- **第一輪**：以前三個核心事件的結構化證據包作背景、機制與替代觀點研究，同批為其他入選新聞提供短中文導讀。只接受已提供的 source_id，不自行加入來源、報價、引文或歷史數據。
- **Python 查核**：每項新增數字與日期必須能追溯到**同一事件**的證據；官方摘錄匹配只證明文字確實出現在來源，不代表分析為真。
- **第二輪**：消除重複、補強邏輯，保留一手證據不足的限制；兩輪仍只能產生 *AI_INTERPRETATION_NOT_VERIFIED* 草稿。
- **未開啟免費層或缺少 API 金鑰**：不呼叫模型，不升級付費；短新聞只能是來源候選，不能冒充完整中文研究。

## 嚴格阻擋規則

`gib/editorial_depth.py` 在每期 `issue.json` 與 GitHub Actions Summary 中留下報告，分別記錄每篇正文的有效分節、中文字數、段落重複率、來源網域數、官方摘錄數與人工簽核的主張數。

必要但不充分的深讀審稿條件包括：背景／重要性／機制完整、反方觀點、限制、5 個有實質內容的分析分節、至少兩個可區分來源網域、至少一處已定位的官方摘錄、3 項已人工簽核且可追溯的主張，以及不使用大量重複段落填充篇幅。

即使通過這些結構檢查，**也不代表事實已證實，更不代表取得正式發行許可**。需實際驗證 2–3 個深讀專題、10 個真實交易日的雙期內容、EPUBCheck、BOOX 離線實機及擁有者核准。
