## 資料與驗收

每次僅抓取已核准的 24 個公開 RSS 加上原系統已存在的 FreeNewsApi、GDELT、官方 RSS。FreeNewsApi 每次查詢最多 8 筆新聞詳情，不另開付費來源。保存原始文章網址、標題、來源、帶時區的日期、取得時間、每路來源健康狀態與失敗原因；不抓取或發行出版社文章全文。

**注意：此 GitHub repository 為 Public。Actions artifact 不應視為私人儲存空間，可能由有權存取公開 workflow 的人士下載。** 本測試只留存已公開來源的新聞網址、標題、時間、來源健康及索引，嚴禁保存帳戶權杖、機密資料、未發布的 Gemini 稿件或受保護的新聞全文。Artifacts 保留 14 日，包括：
- source_index_all.json：當次已發現的去重新聞索引及來源
- snapshot_window.json：實際截稿時段的候選索引，實際起訖時間與編輯 HOLD
- source_health.json：24 路 RSS 與其他免費資料來源的診斷
- capture_summary.json：本次測試的緊湊摘要
- 最後一個工作日晚間額外生成 P2_THREE_DAY_QA_ROLLUP.json，逐一檢查六個時段是否真的有結果；漏執行的時段一律標成缺漏

晚報使用當日早上的 GitHub artifact 進行來源索引差異比較。只記錄新出現原始網址、同址索引文字差異，不聲稱已驗證事件有實質新發展。早報結果缺失時，不會拿前一天或模擬資料冒充晨報基準。

## 自動停止與品質界線

2026/11/02 最後一個晚間工作完成後，由同一 workflow 的 finalizer 使用 GitHub Actions API 停用自身，權限僅供 GitHub Actions 管理，不修改其他 workflow。若最後一次漏執行，後續第一個 scheduled 事件會嘗試補做停用；但日期白名單始終禁止 11 月 3 日以後擷取新聞。若 API 停用失敗，須如實保留失敗資訊，不能宣稱自動停用成功。

這六次只驗證新聞來源時點、候選多樣性與原始網址留存，不會自行完成首三大新聞的主張核實、Gemini 兩輪實質修訂、2–3 篇深讀研究、BOOX/P3 或發行授權。六章節、Style C、原始 frozen_contract.json 與 Zinc Intelligence 均不動；publication 一直為 OFF。
